# Sanad User Portal Coverage

Reference: `Sanad User Portal.pdf`

- Page 1: Customer portal objective maps to the Sanad customer dashboard and request workspace.
- Page 2: Dashboard replaces the legacy calendar with welcome, KPIs, quick actions, active requests, pending actions, and activity.
- Page 3: Service Catalog replaces customer-facing booking discovery and exposes Sanad service details.
- Page 4: Create New Request maps to a customer request wizard using existing `bookings`.
- Page 5: My Requests and Request Detail show lifecycle, timeline, current stage, documents, chat, buzz, billing, and rating.
- Page 6: Document Vault supports personal vault documents and separates request-specific files.
- Page 7: Messages use request-scoped Sanad chat with external contact filtering.
- Page 8: Notifications are shown in a customer notification center with request links.
- Page 9: Billing shows invoices, payments, refunds/VAT-ready history, and invoice exports.
- Page 10: Complaints & Support uses request-linked customer complaints.
- Page 11: Sanad AI Assistant uses admin-managed AI knowledge plus request context.
- Page 12: Customer Profile links to the existing profile/password settings and adds customer preferences visibility.
- Page 13: Security & Privacy is covered through ownership checks, platform-only chat, media storage, audit records, and retention fields.
